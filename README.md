# Dia's World - Interactive Personal Website 🌟

A fun, interactive personal website about Dia (Diana Rose) featuring minigames, collectible objects, and engaging content.

## Features

### 📋 About Section
- Personal information about Dia
- Fun facts and hobbies
- Skills showcase

### 🎮 Interactive Mini Games
1. **Click Away!** - Click floating bubbles to score points before time runs out
2. **Picture Picker** - Find the correct picture that matches the description
3. **Riddle Me This** - Solve fun riddles and test your brain

### ✨ Collectible Objects
- 5 floating collectible items scattered around the page
- Collect them all to unlock a secret message!
- Items: Star ⭐, Heart ❤️, Gem 💎, Flower 🌸, Moon 🌙

### 🎒 Inventory System
- Track your collected items
- See progress towards completing the collection

## How to Use

1. Open `index.html` in a web browser
2. Navigate between sections using the navigation menu
3. Click on floating collectibles to add them to your inventory
4. Visit the Games section to play minigames
5. Explore the Gallery to see featured moments

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Interactive features and game logic

## Local Development

Simply open `index.html` in any modern web browser. No build tools or server required!

```bash
# Using Python's built-in server (optional)
python -m http.server 8000
# Then visit http://localhost:8000

# Or using Node.js http-server (optional)
npx http-server
```
